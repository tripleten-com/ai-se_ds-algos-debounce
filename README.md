# DS & Algos and Debouncing Tasks

This repo has two parts:

- `react-app/` — a small React app with a single component: a list of registered users. You'll use this in the debouncing lesson.
- `typescript-tasks/` — standalone TypeScript exercises. This is where you'll work for the next three lessons.

To set up the TypeScript tasks, navigate to that directory and install dependencies:

```bash
cd typescript-tasks
npm install
```

The `typescript-tasks` directory contains one folder per lesson. Each has a starter file you'll edit, and tests you can run with `npm run test:<lesson-number>` (e.g. `npm run test:02`).

While you work, you can run the TS files with `npx tsx path/to/file`.
